About the System
What are Phantom Units?

A transparent, rule-based framework for recognising every AXXSPACE contributor's work — with a real financial reference value behind each unit.

🏦
Fixed Unit Pool

There are exactly 1,000 Contribution Units in existence. Every unit comes from this fixed pool, ensuring scarcity and fairness.

💶
Real Monetary Value

Each unit carries a reference value of €10 (0.1 unit = €1). The full pool has a reference value of €10,000, the basis for any future buy-back.

📊
Fractional Awards

Units are awarded in increments of 0.1 — from minor tasks (0.1–0.2 units) to strategic contributions (0.9–1.0 units). Every award is fully documented.

🔒
Not Equity

Phantom Units are a recognition & reward mechanism only. They do not represent shares, equity, voting rights, or legal ownership in AXXSPACE.

📋
Full Transparency

Every award is recorded on the contribution ledger with the task, reviewer, date and units. Track your full history and growth over time.

💬
Real-Time Comms

Members receive in-app notifications for unit awards and can message directly with the admin team through the built-in chat system.
